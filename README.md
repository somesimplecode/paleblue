# PaleBlue | An Ethics Simulation
## What this is

A facilitated decision game for college students, inspired by real medical device failures such as Therac-25. Players sit on PaleBlue's Product Safety Review Board and make rapid-fire decisions about Dot (PB-ISS-200), a fictional ingestible sensor. Each decision affects four meters: patient safety, financial stability, public reputation, and employee morale.

The site is styled as a medical device company homepage. The game lives behind the **Employee portal** button.

## Running it

Open `index.html` in a browser, or visit the live site at https://somesimplecode.github.io/paleblue/.

## Facilitator controls

| Key | Action |
|---|---|
| Space | Start the clock or continue |
| A–E | Record the board's choice |
| S | Split vote (applies the default) |
| G | A fired member goes public |
| P | Pause |
| F | Full screen |
| Shift + R | Restart |

## Editing the game

All prompts, endings, and settings are in the `GAME` object at the top of `content.js`.
